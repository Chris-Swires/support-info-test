UK Extension Hosting Decision
UKTEST-3 · UK Extension hosting · Executive summary
Decision

The UK Extension will run on its own Snowstorm server.

Putting it on the shared server slows every existing extension, and extra hardware did not fix it. Moving it back onto the shared server needs Snowstorm changes to the semantic index and the Elasticsearch search layer.

What we tried

Each fix narrowed the gap. None closed it.

  1. Load the UK ExtensionPlatform +24%Every extension slowed. Netherlands worst at +148%.
  2. Double memory and CPUStill +7%About 8× the infrastructure cost, and still slower than before.
  3. Change the search indexPlatform +11%Netherlands improved to +32%. Two others stayed about 31% slower.
  4. Tune furtherWithin 4–7%The three slowest extensions came close to their old speed. Like for like, Netherlands is still 56% slower.
  5. Add memory againNo gainChanged results by 2% or less. Hardware is not the bottleneck.

Why it happens

The slowdown comes from how Snowstorm searches, not from the size of the server.

Every search carries a growing list

Each edit to an extension adds to a list that Snowstorm sends with every search. On extension branches that list is never cleared.

All extensions share one search index

The UK Extension's large content and edit history sit in the same indexes as every other country's, so its weight slows everyone.

It gets worse with time

The cost grows with every edit, not with traffic. A shared server would keep getting slower as the UK and others keep authoring.

The path back to one server

Snowstorm work on the semantic index and Elasticsearch layer comes first.

Snowstorm improvements needed

  • Quick win
    Cache branch search rulesStop rebuilding the same list on every request.
  • Medium
    Store the list inside ElasticsearchUse Elasticsearch terms lookup instead of sending the list with each search.
  • Medium
    Tune the semantic index and queriesBuild on the index changes that already brought the biggest gains.
  • Longer term
    Redesign how versions are hiddenRemove the ever-growing list, or give heavy extensions their own index.

Next steps

  1. Stand up the UK Extension on its own Snowstorm server.
  2. Fund and prioritise the Snowstorm improvements with the Snowstorm maintainers.
  3. Agree the bar for sharing a server: every extension within an agreed margin of its own baseline.
  4. Re-run the full performance suite after each change, then revisit consolidation.
